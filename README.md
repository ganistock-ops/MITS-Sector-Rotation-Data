# MITS 360° Sector Rotation - Public EOD Data Feeds

Official National Stock Exchange of India (NSE) End-of-Day (EOD) quantitative market data feeds for the MITS 360° Sector Rotation Terminal.

## Data Endpoints

- **Sector Intelligence & Breadth:** `data/sectors.json`
- **Stock Leadership Constituents:** `data/stocks.json`
- **Institutional Rotation Insights:** `data/insights.json`
- **Multi-Horizon Forward Outlook:** `data/forward_outlook.json`

## CDN Access

- GitHub Raw: `https://raw.githubusercontent.com/ganistock-ops/MITS-Sector-Rotation-Data/main/data/{feed}.json`
- jsDelivr Edge CDN: `https://cdn.jsdelivr.net/gh/ganistock-ops/MITS-Sector-Rotation-Data@main/data/{feed}.json`

*Updated automatically by MITS 360° Ephemeral Quantitative Pipeline on NSE trading days after market close.*
